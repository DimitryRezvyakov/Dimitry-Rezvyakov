================================Задача 1================================
Приложение отправляет текстовые сообщения пользователям. Со временем появились требования:
Фильтровать нецензурные слова (заменять на ***),
Шифровать сообщение перед отправкой,
Добавлять подпись "Отправлено из приложения v1.0",
Сжимать текст (удалять лишние пробелы),
Эти функции нужно уметь комбинировать в любом порядке. Например, сначала отфильтровать, потом зашифровать, потом добавить подпись.

Условия:
	1.Базовый интерфейс IMessage с методом string GetContent()
	2.Есть простая реализация PlainTextMessage
	3.Количество комбинаций функций может быть большим
	4.Новые функции должны добавляться легко, без изменения существующего кода
========================================================================

================================Задача 2================================
В кофейне есть базовые напитки: эспрессо (2.50€), американо (2€), чай (1.50€). Клиент может добавлять:
молоко (+0.50€),
сахар (+0.20€),
сироп (+0.70€),
взбитые сливки (+0.80€),
Добавки можно комбинировать в любых количествах и порядке. Нужно уметь посчитать итоговую стоимость и получить описание напитка (например, "Чай + лимон + сахар").

Условия:
	1.Базовый класс Beverage с методами GetCost() и GetDescription()
	2.Нельзя создавать отдельный класс для каждой комбинации (их слишком много)
	3.Одна добавка может быть применена несколько раз (например, двойной сахар)
========================================================================

================================Задача 3================================
Есть класс, который пишет логи в файл. Со временем понадобилось:
Добавлять к каждому сообщению временную метку,
Указывать уровень логирования (INFO, ERROR, DEBUG),
Не писать сообщения короче 10 символов,
Накопить 5 сообщений и записать их одним блоком (буферизация),
Все эти функции должны работать как "обертки" над базовым логгером. Их можно включать и выключать, комбинировать.

Условия:
	1.Базовый интерфейс ILogger с методом void Log(string message)
	2.Есть простая реализация FileLogger
	3.Каждая новая функция не должна ломать существующие
	4.Функции можно комбинировать (например, временная метка + уровень + фильтрация)
========================================================================

================================Задача 4================================
В редакторе есть базовые фигуры: круг, прямоугольник, треугольник. Художники захотели добавлять к фигурам эффекты:
обводка (цвет, толщина),
заливка градиентом,
тень,
пунктирная линия,
Эффекты можно накладывать друг на друга в любом порядке. Например, сначала обводка, потом тень, потом градиент.

Условия:
	1.Базовый интерфейс IShape с методом void Draw()
	2.Базовые фигуры умеют рисовать себя простым способом
	3.Нельзя создавать класс для каждой комбинации эффектов
	4.Новые эффекты должны добавляться легко
========================================================================

================================Задача 5================================
Нужно обрабатывать текст цепочкой преобразований. Доступны операции:
перевод в верхний регистр,
удаление пробелов в начале и конце,
замена одного слова на другое,
удаление знаков препинания,
Операции можно применять в любом порядке. Например: удалить пробелы → перевести в верхний регистр → заменить "HELLO" на "HI".

Условия:
	1.Базовый интерфейс ITextProcessor с методом string Process(string text)
	2.Есть простая реализация, которая возвращает текст без изменений
	3.Каждая операция — отдельный класс
	4.Операции должны быть взаимозаменяемыми и комбинируемыми
========================================================================
