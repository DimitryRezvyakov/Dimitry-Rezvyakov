Во всех задачах запрещено использовать DI.

================================Задача 1================================
Требуется сделать соединение с базой данных эксклюзивным для приложения (одно соединение на приложение)

Условия:
	1. Нельзя создавать новое подключение на каждый запрос.
	2. Подключение должно создаваться только при первом обращении.
	3. Потокобезопасность.
========================================================================

================================Задача 2================================
Требуется сделать единый кеш для всех частей приложения.

Условия:
	1. Кэш должен быть доступен из всех частей приложения.
	2. Все должны видеть одни и те же закешированные данные.
	3. Возможность очистки кеша из любой части приложения.
========================================================================

================================Задача 3================================
Требуется создать диспетчер для обработки задач.

Условия:
	1. Каждый модуль должен добавлять задачу в очередь в диспетчере.
	2. Диспетчер выполняет задачи в порядке добавления в фоновом режиме.
	3. Нужно отслеживать статус всех задач.
========================================================================

================================Задача 4================================
Написать настройки для приложения.

Условия:
	1. Настройки должны быть доступны из любой части приложения.
	2. Настройки не изменяемые во время работы приложения.
	3. Настройки читаются один раз при старте приложения.
========================================================================

================================Задача 5================================
Написать менеджер для печати документов. Принтер может печатать тольо один документ одновременно

Условия:
	1. Все файлы отправляемые на печать должны быть переданы в принтер в порядке их отправления.
	2. Потокобезопасность.
	3. Отображать статус печати.
	4. Доступ с любого модуля программы.
========================================================================
