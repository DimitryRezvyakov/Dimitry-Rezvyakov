================================Задача 1================================
Интернет-магазин продает компьютеры, которые можно собрать из отдельных компонентов:
процессор, видеокарта, материнская плата, оперативная память, накопители (SSD/HDD),
блок питания, система охлаждения, корпус. Пользователь может выбрать разные бренды,
модели и характеристики для каждого компонента.
Некоторые компоненты должны быть совместимы друг с другом (например, процессор должен подходить к сокету материнской платы,
блок питания должен иметь достаточную мощность).

Условия:
	1.Создание компьютера через конструктор с 15+ параметрами невозможно
	2.Нужно обеспечить пошаговую сборку: сначала выбирается платформа (Intel/AMD), затем совместимые компоненты
	3.Должна быть валидация совместимости на этапе сборки (нельзя собрать Intel процессор с AMD материнской платой)
	4.Пользователь может добавить несколько накопителей (SSD для системы, HDD для данных)
	5.Должны быть предустановленные конфигурации (офисный ПК, игровой ПК, рабочая станция)
========================================================================

================================Задача 2================================
Маркетинговая платформа позволяет создавать сложные email-рассылки с множеством параметров:
тема письма, текст, HTML-шаблон, изображения, кнопки с ссылками, вложения, время отправки,
сегменты аудитории, A/B тестирование (разные варианты письма),
отслеживание открытий и кликов. Каждая рассылка может иметь свою структуру и набор элементов.

Условия:
	1.Письмо может состоять из блоков: заголовок, текст, изображение, кнопка, список, видео
	2.Блоки можно добавлять в любом порядке и комбинировать
	3.Некоторые блоки требуют обязательных полей (например, у кнопки должна быть ссылка)
	4.Должна быть возможность клонировать существующую рассылку и модифицировать ее
	5.Нужно валидировать корректность рассылки перед отправкой (не пустое тело, валидные ссылки, корректный сегмент аудитории)
========================================================================

================================Задача 3================================
Туристическое агентство предлагает сложные туристические пакеты, которые включают:
перелет (туда/обратно, класс обслуживания), трансфер (из аэропорта в отель и обратно),
проживание (отель, тип номера, питание), экскурсии (набор доступных опций), страховка,
дополнительные услуги (аренда авто, визовая поддержка).
Клиент может выбирать опции в разных комбинациях, но некоторые опции взаимоисключающие.

Условия:
	1.Пакет может собираться пошагово: сначала выбор направления и дат, затем отель, затем опции
	2.Некоторые опции зависят от предыдущих выборов (например, экскурсии доступны только в определенных отелях)
	3.Должна быть возможность сохранять промежуточные состояния сборки
	4.Нужно рассчитывать итоговую стоимость динамически по мере добавления опций
	5.Должны быть готовые пакеты ("Семейный отдых", "Романтический уикенд", "Экстремальный тур")
========================================================================

================================Задача 4================================
Вы разрабатываете ORM-библиотеку, которая позволяет строить сложные SQL-запросы в объектно-ориентированном стиле.
Запрос может включать: выбор полей (SELECT), условие (WHERE), сортировку (ORDER BY),
группировку (GROUP BY), объединения (JOIN), подзапросы, лимиты и пагинацию.
Разные части запроса могут добавляться в произвольном порядке, но результирующий SQL должен быть синтаксически корректен.

Условия:
	1.Запрос строится пошагово через fluent-интерфейс: query.Select(...).From(...).Where(...).OrderBy(...)
	2.Методы могут вызываться в любом порядке, но валидация проверяет наличие обязательных частей (SELECT, FROM)
	3.JOIN-ы могут быть нескольких типов (INNER, LEFT, RIGHT, FULL) и могут добавляться несколько
	4.WHERE-условия должны уметь комбинироваться (AND/OR) и группироваться с помощью скобок
	5.Должна быть поддержка параметризованных запросов для защиты от SQL-инъекций
========================================================================

================================Задача 5================================
Бизнес-аналитическая платформа позволяет пользователям создавать кастомные отчеты.
Отчет может включать: источники данных (таблицы, представления), фильтры, группировки,
агрегатные функции (сумма, среднее, минимум, максимум), сортировку,
форматирование чисел и дат, диаграммы (разные типы), экспорт в разные форматы (PDF, Excel, CSV),
расписание автоматической отправки.

Условия:
	1.Отчет строится из набора компонентов: заголовок, таблица, диаграмма, фильтры, итоги
	2.Компоненты можно добавлять, удалять и переупорядочивать
	3.Некоторые компоненты зависят от других (диаграмма требует выбранных полей для осей X и Y)
	4.Должна быть валидация перед сохранением (все поля выбраны, фильтры корректны)
	5.Должны быть шаблоны отчетов ("Продажи по месяцам", "Динамика трафика", "Анализ клиентов"), которые можно использовать как основу для новых отчетов
========================================================================
